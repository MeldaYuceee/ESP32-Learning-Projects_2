# ESP32-Learning-Projects_2

This repository contains ESP32 projects that I developed while learning embedded systems and IoT concepts.

The projects are currently developed in simulation environments because I do not yet have access to all physical hardware components. Even so, I focus on understanding real system logic and practical use cases.

## Projects

### Drone Telemetry Dashboard
A simple ESP32-based telemetry dashboard project.

Features:
- Fake flight data generation
- Altitude, speed and battery monitoring
- Web dashboard system
- Low battery warning
- LED alert system

This project was developed to learn the basic logic behind drone telemetry systems, remote monitoring applications and IoT-based tracking systems.

More projects will be added over time.
